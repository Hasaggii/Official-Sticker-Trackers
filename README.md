# ⚽ FWC Sticker Tracker

A mobile-optimized web app to track your Panini FIFA World Cup sticker collection.

## How to use
- Tap a sticker button to mark it as collected (turns green)
- Tap a checked sticker to undo — you'll be asked to confirm
- Your progress is saved automatically in your browser

## Deploy
Deployed via Vercel. Push to GitHub and connect the repo on vercel.com.
